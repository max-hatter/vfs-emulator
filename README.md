# VFS Emulator (Вариант 27) — Этап 1

Минимальный прототип эмулятора оболочки UNIX-подобной ОС.

## Возможности

- GUI (tkinter), заголовок окна содержит имя VFS
- Парсер с поддержкой кавычек и раскрытия переменных окружения (`$HOME`)
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка ошибок

## Запуск

python -m src.main

## Тесты

pytest tests/ -v
